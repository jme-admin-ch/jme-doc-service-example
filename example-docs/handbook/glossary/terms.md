# Terms

| Term              | Meaning                                                                                       |
| ----------------- | --------------------------------------------------------------------------------------------- |
| Maintainer        | A member of the team who may merge a change and ratify a release                              |
| Release           | A tagged version whose artifacts were published by the build of that tag                     |
| Documentation set | What one upload carries: the pages of one subject, uploaded from one revision of a repository |
| Handbook          | This site - how the team works, as opposed to how its system is built                         |
