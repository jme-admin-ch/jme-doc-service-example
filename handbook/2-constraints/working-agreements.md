# Working Agreements

These are not the constraints of a system but of a team. They are few on purpose, and each one exists because
the team once missed it.

| Agreement                                     | Why                                                                        |
| --------------------------------------------- | -------------------------------------------------------------------------- |
| Every change goes through a pull request      | A second pair of eyes is the cheapest test there is                        |
| The main branch is always releasable          | A fix must never wait for an unfinished feature                            |
| Documentation changes with the code           | Documentation that is written later is documentation that is never written |
| Everything committed is English               | The documentation is read by teams that do not share the team's language   |
| A failing build is fixed before anything else | Every change made on top of a red build is a change nobody has tested      |
